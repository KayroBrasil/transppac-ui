1. COPIAR O PROJETO PARA SUA MÁQUINA:

git clone https://github.com/KayroBrasil/transppac-ui.git

2. CRIAR RAMIFICAÇÃO DA SUA TAREFA:

git branch nome-da-tarefa

3. TROCAR PARA SUA RAMIFICAÇÃO:

git checkout nome-da-tarefa

4. DESENVOLVER AS PÁGINAS SOLICITADAS;

5. VERIFICAR QUAIS ARQUIVOS FORAM MODIFICADOS:

git status

6. ADICIONAR OS ARQUIVOS ALTERADOS:

git add nome-do-arquivo nome-da-pasta

7. SALVAR AS ALTERAÇÕES LOCALMENTE:

git commit -m "Nome da tarefa finalizada."

8. ENVIAR PARA O REPOSITÓRIO REMOTO:

git push -u origin nome-da-tarefa

9. BAIXAR TODAS AS ALTERAÇÕES FEITAS:

git pull origin main

10. REPETIR OS PASSOS 2 AO 10.
